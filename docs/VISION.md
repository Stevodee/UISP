# Universal Immersive Scene Platform (UISP)

## Vision

The Universal Immersive Scene Platform (UISP) is an open architecture for creating, storing, publishing, and sharing immersive visual experiences through standard web technologies.

The goal is not to create another panorama viewer or another VR application.

The goal is to define a universal scene format capable of representing images, panoramas, videos, 3D environments, spatial audio, annotations, documents, and interactive experiences within a single coherent framework.

The platform should remain browser-first, lightweight, extensible, and independent of any rendering engine.

---

## Design Principles

- Open architecture
- Browser first
- Progressive enhancement
- Renderer independent
- Standards based
- Human readable
- AI friendly
- Accessible
- Modular
- Extensible

---

## Long-Term Goals

A single Scene should be capable of containing:

- Standard images
- Large zoomable images
- Stereo images
- Panoramas
- Stereo panoramas
- Video
- 360° video
- Spatial audio
- Narration
- Music
- Interactive hotspots
- Documents
- Maps
- Timelines
- 3D models
- AI-generated annotations
- Guided tours
- External web resources

---

## User Experience

A Scene should work inside:

- Desktop browsers
- Mobile browsers
- Tablets
- Embedded web pages
- Museum kiosks
- Smart displays
- VR headsets
- Future immersive devices

The same URL should adapt itself to the capabilities of the device.

---

## Core Philosophy

Every meaningful object inside a scene should be addressable.

Every object should have:

- Identity
- Position
- Metadata
- Associated media
- Relationships
- Actions

The viewer should simply render the scene.

The scene description should remain independent of the viewer.

---

## Success Statement

A user should be able to open any Scene in a standard browser and explore an interactive visual experience without requiring specialized software.
